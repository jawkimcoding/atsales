# 2026 aT 농산물 온라인 마케터 실적 분석 대시보드

## 🚀 대시보드 실행 방법

### 1) 원클릭 실행 (Windows)
- 저장소 내 `start_dashboard.bat`을 더블 클릭하면 브라우저에서 대시보드가 즉시 열립니다.

### 2) 개발 모드 실행
```bash
npm install
npm run dev
```
- 브라우저에서 `http://localhost:5173` 접속

### 3) 프로덕션 빌드
```bash
npm run build
```
- `dist/` 폴더에 생성된 정적 번들을 웹 서버나 GitHub Pages에 배포 가능

---

## ⚡ 향후 신규 월(9월, 10월...) 자동 집계 & 차감 기능 사용법

1. 대시보드 우측 상단의 **[누적 로우데이터 추가 & 차감]** 버튼 클릭
2. 새로 취합된 누적 엑셀 파일(`.xlsx`)을 드래그앤드롭하여 업로드
3. 대시보드가 `①농산물raw` 시트를 분석하여 기존 누적치와의 차감을 자동으로 계산
4. 표 1~7 및 그래프에 해당 월 실적이 실시간으로 자동 추가 및 반영
5. 상단의 **[엑셀 다운로드 (.xlsx)]** 버튼으로 최신 취합본 내보내기 가능
